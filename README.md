# Shadow Kunai: Survivor

Top-down 2D hack-n-slash / bullet heaven для Android. Тёмное додзё в стиле японской туши, неоновые атаки, автокаст 5 скиллов, 20 способностей с аугментациями 3/7/10 и 8 слияний.

**Документы:** [PLAN.md](./PLAN.md) · [ARCHITECTURE.md](./ARCHITECTURE.md)

## Что уже работает

- [x] Vite + TypeScript strict + PixiJS v8 (WebGL) + Tailwind 4
- [x] Fixed-timestep 60 Гц, ObjectPool, SpatialGrid 128×128, Camera со screen-shake
- [x] Плавающий тач-джойстик + WASD для десктопа
- [x] Игрок, i-frames, сбор XP, магнит и слияние сфер при >150
- [x] Волны врагов: генин, ассасин, самурай, лучник, мини-босс каждые 3 минуты
- [x] 20 скиллов с авто-кастом и ветками аугментаций 3/7/10
- [x] 8 рецептов слияний (5 пар + 3 тройки), карточка «СЛИЯНИЕ» с 5 уровня компонентов
- [x] Ульта 50 ур. «Оги: Небесный Вихрь Теней»: ASCEND → BARRAGE → DESCEND, цепное продление, посадка
- [x] UI: драфт 5 из 20, HUD, карточки левел-апа, экран итогов
- [x] Neo-Edo Ink UI: палитра, Cinzel/PT Serif/JetBrains Mono, chamfer-геометрия, 20 SVG-иконок
- [x] Процедурные текстуры 2x без PNG (4 прохода туши), hit-flash, цифры урона
- [x] MeshRope-шлейфы, hit-stop 35–60 мс, направленная тряска камеры
- [x] Арена: тайловый пол додзё, энсо-печать, дрейфующий пепел, виньетка
- [x] Процедурный звук WebAudio (в духе ZzFX)
- [x] Capacitor Android (portrait) + GitHub Actions сборка APK

## Управление

- **Тач:** касание в любом месте — плавающий стик; скиллы кастуются сами.
- **Кнопка УЛЬТ** справа снизу появляется на 50 уровне. Рядом переключатель `АВТО`.
- **Клавиатура:** WASD/стрелки, `Q`/`Space` — ульта, `U` — dev-разблокировка 50 ур., `1..5` — dev-прокачка слотов.
- **UI:** кнопки дают виброотклик, 60 мс алую вспышку и синтезированный клик.

## Локальный запуск

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # tsc --noEmit + vite build
```

## Android APK

APK собирается в GitHub Actions при каждом пуше в `master` (workflow `Build Android APK`) и лежит в артефактах запуска: `shadow-kunai-debug-apk`.

Локально (нужен Android SDK + JDK 21):

```bash
npm run apk
```

Настройки приложения — `capacitor.config.ts`, id `com.shadowkunai.survivor`, ориентация portrait.

## Проверка

- `npm run build` — tsc strict + production bundle.
- Игровой цикл прогнан в headless Chromium (SwiftShader): драфт → бой → карточки → слияние «Химический Апокалипсис» → ульта с авто-активацией → смерть → рестарт. Ошибок страницы нет.
- Все 20 скиллов проверены кастом в трёх разных забегах (по 5 способностей), добивания и дроп XP работают.
- В DEV-сборке доступен отладочный объект `window.__shadow` (state, world, systems) — в APK/проде он не создаётся.

## Известные ограничения / техдолг

- Эффекты синергий пока в основном выражаются стат-бустом и флагами; уникальные механики 8 эволюций реализованы частично.
- Часть файлов (`SkillSystem.ts`, `AdvancedCasts*.ts`) превышает целевые 250–300 строк — требуется разбиение на шаге полировки.
- Dev-хоткеи `U` и `1..5` оставлены для тестирования и будут убраны перед релизом.
- Баланс волн и урона требует плейтестов на реальном устройстве.
